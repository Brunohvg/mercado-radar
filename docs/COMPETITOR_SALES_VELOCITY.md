# Pesquisa competitiva: giro de vendas
A pesquisa existente aceita nome, SKU ou MLB. Para o piloto, pesquisar arame encapado nº 22, nº 26, arame floral, hastes 40 cm, hastes 15 cm e carregar mais ofertas. Usar Monitorar até 50 ofertas para salvar a amostra filtrada. O cron existente atualiza os itens API; os itens PAGE dependem de novas capturas pela extensão.
Média histórica = contador / idade oficial em dias × 30. Limites inferiores são identificados. Ritmo recente = diferença entre contadores numéricos validados / dias × 30, janela de 2 a 30 dias; não usa snapshots legados (podem conter zero artificial), contadores ausentes, regressivos ou arredondados explicitamente como faixas. API_VALIDATED marca somente os novos snapshots; a API de leitura continua expondo API. Contadores de terceiros não são pedidos comprovados. Não se presume data a partir de MLB.
Sem migração. Antes de merge: npm test, npm run typecheck, npm run build, testes de navegador, teste com conta real e cron; verificar busca, comparação, kits, observações PAGE, falta de campos e permissões. Não publicar automaticamente nem alterar produção.
